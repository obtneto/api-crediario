## Regras tecnicas
- Componentes devem ser pequenos, reutilizaveis e previsiveis.
- Separar apresentacao, logica e estado quando necessario.
- Criar props claras e bem nomeadas.
- Evitar estilos inconsistentes.
- Garantir responsividade mobile-first quando possivel.
- Considerar acessibilidade com `aria-label`, contraste, foco e navegacao por teclado.
- Pensar em UX real: feedback visual, confirmacao, loading, empty state e mensagens de erro.

## Design system
- Priorizar consistencia visual.
- Usar espacamento previsivel.
- Padronizar variantes de botao, input, card, modal e tabela.
- Definir estados: default, hover, focus, active, disabled, loading, error, success.
- Evitar criar componente generico demais sem necessidade real.
- Componentes devem ter API simples e intuitiva.
